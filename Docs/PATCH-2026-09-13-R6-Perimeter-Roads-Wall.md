# 江城大学——外围城市道路与校园围墙修正（R6最高优先级补丁）

版本：`PATCH-2026-09-13-R6`

本文件为《江城大学——数据源统一更新、废止与覆盖说明（PATCH-2026-09-12-R5）》的增量最高优先级补丁。未在本文件中明确修改的R5内容继续有效。

## 1. 覆盖关系

本文件仅覆盖R5第五节“外围四条城市道路旧中心线废止”中的四条外围城市道路几何表达，以及新增校园围墙工程基线。

优先级：

`R6 > PATCH-2026-09-12-R5 > 第17-R4 > 第17项旧外围道路`

下列内容保持不变：

- 南侧道路仍为大学路；
- 西侧道路仍为学府路；
- 北侧道路仍为致远路；
- 东侧道路仍为长虹路；
- 四条道路控制宽度仍按约36m；
- 校园面积与第17项6.513km²法定/规划用地边界暂不改变；
- 南门、西门、北门、东门、东南后勤门及医院、剧院、科研科技园社会接口的功能关系不改变；
- R5附属医院一体化组织不改变。

## 2. 新的外围道路形态原则

外围四条城市道路改为参考总平面图所示的“长直线段 + 角部缓和曲线”形态，不再做连续波浪式Bezier曲线。

正式规则：

1. 每一侧以一段或两段长直切线作为主要视觉骨架；
2. 只有四个角部以及必须贴合城市接口的位置允许使用圆曲线/缓和曲线；
3. 禁止对整条道路使用自由Bezier自动平滑导致道路产生蛇形摆动；
4. 四条路在鸟瞰视角下应呈现近似规则、相对笔直的四边城市界面；
5. 道路仍位于校园用地边界之外；道路边缘与用地边界原则上保持约10～20m城市人行/绿化缓冲，局部角部允许适度放宽，但不得重新出现90～150m无定义空带。

## 4. 角部处理

四个道路转角不得做折线尖角。道路生成采用：

`Straight Tangent -> Circular/Clothoid Transition -> Straight Tangent`

角部建议圆曲线等效半径：`140～220m`。

实际生成时允许在不进入校园边界、不破坏校门/医院/剧院/科研园接口的前提下，对角部切点做约±15m工程微调；不得改变四条长直主段的整体方向与视觉效果。

## 5. 校园围墙总体原则

新增连续校园围墙系统。围墙用于3D视觉与校园边界管理，不替代6.513km²用地边界数据。

围墙形态参照总平面图：

- 大部分沿四周道路平行布置；
- 长边尽量采用长直墙段；
- 四角采用柔和转折，不做锯齿或密集折线；
- 校门、医院社会入口、急救接口、剧院社会入口、科研科技园访客接口、东南后勤门处断开；
- 围墙外侧保留连续城市绿带/人行空间，围墙内侧保留校园绿化带；
- 鸟瞰时形成清楚但不过度突兀的校园边界。

围墙视觉基线：

- 总高度约 `1.9～2.1m`；
- 下部暖灰石材/混凝土基座约 `0.4～0.5m`；
- 上部深灰金属通透栏杆约 `1.4～1.6m`；
- 普通墙段不采用高大不透明实体墙；
- 主要校门两侧可使用更厚重的石材墙柱与校名标识；
- 围墙、门柱和导视材质继续服从全校“暖灰石材 + 深灰金属 + 江城蓝识别”的建筑语言。

## 7. 围墙开口

围墙生成器必须为下列接口预留开口，开口中心应投影到最近围墙段，不得通过移动永久ID坐标来迁就模型：

- `GATE-SOUTH`：主校门，建议净开口约42m；
- `GATE-WEST`：西门，约34m；
- `GATE-NORTH`：北门，约42m；
- `GATE-EAST`：东门，约34m；
- `GATE-SERVICE-SE`：东南后勤门，约24m；
- `ENT-HSP-SOCIAL`：附属医院社会入口，约32m；
- `ENT-HSP-EMERGENCY-CITY`：医院急救城市接口，约14m，必须与普通社会入口分离；
- `ENT-THEATER-PUBLIC`：戏剧表演中心社会入口，约32m；
- `ENT-RDI-VISITOR`：科研科技园访客入口，约28m。

围墙开口与既有入口之间允许通过短直线/缓弯引道连接；不得为追求围墙完全贴合而移动已冻结的医院、剧院、法学院、体育馆等主体建筑。

## 8. Unity / CampusData实现硬规则

1. 外围道路必须由CampusData生成，禁止在Unity场景中手工拖动形成第二套坐标；
2. 道路采用分段直线与角部圆曲线，不允许全局Bezier产生过度弯曲；
3. 围墙单独作为PerimeterWall数据对象，不与道路Mesh合并；
4. 围墙按Chunk拆分加载，远景使用低成本HLOD/合批；
5. 道路、围墙、校门三者必须共享同一坐标基线；
6. Stage B空间校验新增：道路不得进入校园用地多边形；围墙不得越出校园用地；围墙开口必须能连接对应Entrance/Gate；
7. 当前四条路与围墙的修改只改变外围城市界面，不改变校内博雅环路、R3内部主路、水系、建筑与体育坐标。

## 9. 废止项

自R6起，R5第五节列出的R4外围道路中心线仅保留为历史记录，不再用于CampusData、Unity灰盒、总平面效果图或正式建模。

后续任何总平面效果图必须表现为：四周城市道路以长直段为主、角部缓弯；校园围墙连续围合并与道路大体平行；校门和社会接口在围墙处形成明确开口。
