# 江城大学总平面 R7 布局差异审计——以用户确认母图为最高布局参考

状态：`AUDIT COMPLETE / COORDINATE OVERRIDE NOT YET FROZEN`

## 1. 审计目的

本审计不讨论材质、阴影、树木密度等美术问题，只比较：

- 建筑布局；
- 道路布局；
- 中央轴线；
- 学院/生活/体育组团组织；
- 校园边界与城市道路的空间关系。

用户已明确：当前上传的《江城大学校园总平面母图》是布局效果的最高参考。R6现有工程数据仍作为坐标与对象清单基线，但若其布局关系与母图明显冲突，则后续应建立R7坐标修订，而不是继续在R6 FINAL SVG上打补丁。

## 2. 总体判断

现有R6并非整体功能分区错误。以下宏观锚点与母图基本一致，原则上继续保留：

- 西南：附属医院 + 医学组团；
- 西门：法学院 + 法律援助中心；
- 西北：科研科技园；
- 北门：综合体育馆 + 第一400m田径场；
- 东北：艺术学院 + 戏剧表演中心；
- 东部：人文社科区 + 东苑；
- 南部：南苑 + 中央商业；
- 东南：第二体育中心；
- 中部：澄湖 + 博雅图书馆。

真正导致现有SVG布局观感明显弱于母图的，是“微观和中观组织方式”而不是大区位置。

## 3. P0：必须优先修正的问题

### P0-1 外围4条城市道路必须是直线

已执行修正：

- 大学路：东西向直线；
- 致远路：东西向直线；
- 学府路：南北向直线；
- 长虹路：南北向直线。

校园围墙/校界允许在四条道路内部变化，但不得牵引城市道路中心线弯曲。

该条已进入自动验证，后续不得回退。

### P0-2 中央礼仪轴建筑次序与母图不一致

当前R6关键对象：

- CEN-01 主图书馆：`(0,-160)`，位于主轴，符合母图；
- CEN-02 行政中心：`(0,-500)`，当前占据主轴核心位置；
- CEN-03 大学会堂：`(250,-360)`，明显偏离X=0中央轴；
- 南门：`(0,-1098)`；
- 澄湖：位于主轴北端核心。

母图表现的是非常明确的：

`南门 → 中央礼仪空间/明德会堂 → 博雅图书馆 → 澄湖`

其中明德会堂处于视觉中轴，而不是偏到东侧。

因此R7必须：

1. 将CEN-03明德会堂重新纳入X≈0中轴；
2. CEN-02行政中心不应继续独占中轴正面，改为中轴侧翼或与公共建筑组团整合；
3. 中轴南北保持连续的步行/礼仪空间，不应被曲折机动车线切碎。

CEN-03新的精确Z值与CEN-02侧移方向本审计暂不冻结，应在R7坐标重排阶段统一求解。

### P0-3 内部道路“工程避障线”过强，缺少母图的总平面秩序

现有R3内部道路主要为了逐对象避障，尤其：

- ROAD-BOYA-RING；
- ROAD-TRANSIT-C；
- ROAD-QINGNIAN-* 多连接段；
- ROAD-GEZHI-*；
- ROAD-JIANGXIN-*。

从工程连通角度可以使用，但整体视觉呈现为多次折转、蛇形和碎片连接。

母图的道路逻辑则是：

- 主路长直；
- 学院/宿舍形成清晰街区；
- 只有澄湖周边、景观节点和转角才明显使用曲线；
- 中央礼仪轴以步行景观空间为主；
- 局部支路从主骨架短距离接入建筑组团。

R7道路重构原则应变更为：

`长直主干 + 少量正交次干 + 组团短支路 + 湖区局部曲线`

而不是继续以“对每栋建筑逐点绕行”为主要几何语言。

### P0-4 建筑单体是“表格式落点”，不是“组团式校园”

R6大量学院建筑使用非常规则的100～120m间距、同一rotationY、两三排矩形布局。

例如西部工程/信息区，从航空、土木、建筑、环境、机械、材料、电气、ICT、电子、AI、CSE等，整体更接近数据表网格，而母图表达的是：

- 3～6栋组成一个学院/学部院落；
- 建筑之间形成中庭、入口广场、绿地；
- 不同组团之间由主路和绿带分隔；
- 同一片区内建筑长度、朝向和前后错位存在变化。

R7应保留学院所属大区，但允许在大区内部重新组织建筑中心和rotationY。

## 4. P1：需要重组但不需要大规模换区的问题

### P1-1 西部科研 / 西苑 / 工程 / 信息四个板块需要更清楚分层

母图从西北到西南大体是：

`科研科技园 → 西苑 → 工程学院群 → 信息学院群 → 法学院 → 医院`

实际不是严格一列，但每个板块都有清晰边界。

R6大区位置基本正确，但工程/信息区过宽、建筑密度均匀，导致科研、西苑、工程、信息之间的“板块切换感”不足。

R7建议：

- 科研科技园保持西北独立；
- 西苑保持靠西、形成住宿院落；
- 工程学院集中在西部中北；
- 信息/计算机/AI集中在西部中南；
- 法学院继续贴西门；
- 医学区继续保持西南城市接口。

### P1-2 东部人文社科、东苑、经管区需要形成三个独立街区

母图关系很清楚：

- 人文社科：澄湖东侧；
- 东苑：更靠东侧；
- 经管：人文以南、第二体育中心以西北。

R6宏观位置正确，但建筑/道路缺少明确的组团边界和内部院落。

R7无需整体搬迁，只需重做街区骨架和建筑组团。

### P1-3 北体育中心与北苑需要强化“中央体育、宿舍两翼”

母图：

`北门 → 综合体育馆 → 第一田径场`

是极强中轴，宿舍和球场在两侧展开。

R6中ATH-01、ATH-05的总体位置正确，北苑也设置成东西两翼，因此大方向保留。

R7需优化：

- 北苑不能形成连续宿舍墙阻挡体育中轴；
- 球场和宿舍交错布置，但保留赛事集散空间；
- 体育馆前广场应比普通学院广场更完整。

### P1-4 第二体育中心要成为完整体育组团

当前ATH-11/12/13和户外球场数量已齐全，但总图上更像“设施落点集合”。

母图要求读成一个完整板块：

- 第二400m田径场为核心；
- 游泳馆/体育服务建筑靠近；
- 网球、篮球、排球等集中成场地群；
- 与南苑、东南后勤保持明确道路边界。

### P1-5 四苑宿舍需要从“整齐排表”升级为“生活组团”

现有56栋宿舍数量与四苑分布继续保留。

但R7需要改变微观组织：

- 3～5栋组成小院/小组团；
- 食堂、超市、绿心、球场嵌入组团；
- 道路不应把宿舍切成纯工业式网格；
- 宿舍排布允许错位、围合和不同朝向模板组合。

不改变：42本科 + 10研究生 + 4国际住宿总量。

## 5. P2：可在主结构完成后处理

### P2-1 围墙和校园轮廓的视觉规整

合法用地边界可以继续保留R6约6.513km²控制线。

但母图中的可见围墙更接近：

- 四边长直/缓直；
- 四角柔和；
- 不与城市道路重合；
- 不出现密集锯齿。

R7可在不改变校园面积基线的前提下，进一步规整可见围墙线。

### P2-2 澄湖外围路径与中央绿地

澄湖本身位置、尺度与母图基本一致，可继续作为冻结锚点。

需要修改的是：

- 湖南侧图书馆前空间；
- 湖西/湖东学院边界；
- 湖岸道路应减少机动车感，增强慢行景观环；
- 桥、岛、草坪和中轴应服务中央核心，而不是被道路折线切碎。

## 7. R7道路布局目标

R7不再以“28条旧道路坐标全部原样保留”为目标，而改为保留道路功能和名称体系，重新求解中心线。

总平面必须满足：

1. 四条外围城市道路绝对直；
2. 校园内部主要机动车路优先长直；
3. 中央礼仪轴X≈0连续；
4. 博雅环路读起来是一个清楚的校园主环，而不是蛇形避障线；
5. 西部、东部和南部形成清楚街区；
6. 澄湖周边曲线主要服务景观与慢行；
7. 社会车辆不得穿越中央校园；
8. 医院、剧院、科研访客继续使用独立城市接口。

## 8. R7建筑布局目标

1. 保留40个学院/学术单位体系；
2. 保留204条建筑/主要设施对象清单，除非后续专门废止；
3. 保留56栋学生住宿总量；
4. 不追求所有建筑等间距；
5. 每个学部形成3～6栋建筑的组团/院落；
6. 组团之间保留道路、绿带或广场；
7. 主要地标正对轴线或公共空间；
8. 建筑朝向服从组团和道路，而不是仅按全区统一90°/270°批量设置。

## 10. 审计结论

当前R6存在的主要问题不是“功能区都错了”，而是：

> 功能区大方向正确，但建筑和道路仍然表现为工程数据落点；母图表现为经过城市设计和校园规划组织后的成熟组团。

因此正确方向是：

> 保留R6对象体系与大区锚点，重做R7中央轴、内部道路骨架、学院组团和四苑微观布局。
